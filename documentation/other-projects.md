# Related projects

We pay attention to the scene of electronic bandoneon projects. If you are
working on one and would like it mentioned here, reach out — together we are
stronger.

The information below is collected on a best-effort basis from public sources
and may be incomplete or out of date. Corrections are welcome.

## Bandonino

Author
: Danny Chapman

Year
: 2024

Notes
: USB MIDI only. Bellow sensing via a load cell. Unisonoric (Peguri/Manoury layout).

License
: MIT.

References
:   - [Project repository](https://github.com/Rowlhouse/bandonino)
    - [Build and demonstration video](https://www.youtube.com/watch?v=M0wQ6heuBrk)

## Bandolica

## Bandoneon 2.0

Author
: Juan Ramos, Esteban Calcagno, Ramiro Vergara, Pablo Riera, Joaquín Rizza

Year
: 2018 - 2023

Notes
: Interdisciplinary academic project at the National University of Quilmes,
  Argentina, building an expressive, accessible electronic bandoneon with a
  measured-acoustics synthesis model. First prototype named "Alfa"; a successor
  named "Astor" was announced. Latest public output is the 2023 NIME paper.

License
: None known — academic research project.

References
:   - [Project page (Juan Ramos)](https://www.jaoramos.com.ar/bandoneon-2-0/)
    - [NIME 2022 paper (best paper award)](https://nime.pubpub.org/pub/31l4lgcd)
    - [NIME 2023 follow-up: embedded wavetable synthesizer](https://nime.org/proceedings/2023/nime2023_23.pdf)
    - [Computer Music Journal article](https://direct.mit.edu/comj/article-abstract/46/1-2/40/114878/An-Electronic-Bandoneon-with-a-Dynamic-Sound)
    - [UNQ science agency article](https://agencia.unq.edu.ar/?p=5437)

## Bandonberry

Author
: Jose Bentancour (Universidad de la República, Uruguay)

Year
: 2018 - 2019

Notes
: Fully 3D-printed MIDI bandoneon built around a Raspberry Pi as a learning
  simulator; 71 buttons via an SPI port expander, onboard I2S audio. No bellow
  sensing.

License
: MIT.

References
:   - [Project repository](https://github.com/jebentancour/Bandonberry)
    - [Thesis (Colibri, UdelaR)](https://www.colibri.udelar.edu.uy/jspui/handle/20.500.12008/23433)

## BandoMIDI

Author
: HLeBoucher

Year
: 2020

Notes
: Acoustic bandoneon retrofitted into a silent MIDI instrument using magnets and
  magnetic sensors read by an Arduino, with an Odroid C1+ for sound. Button
  presses only — no bellow sensing (the author notes this as a limitation).

License
: Open source (GitLab).

References
:   - [Hackaday.io project](https://hackaday.io/project/170753-bandomidi)
    - [Source repository](https://gitlab.com/HLeBoucher/bandomidi)
    - [Hackaday article](https://hackaday.com/2020/04/13/quieting-down-a-bandoneon-accordion-with-midi/)

## bandoMIneDonI

Author
: 3araht

Year
: 2021 - 2024

Notes
: MIDI keyboard kit with a bandoneon button layout and no bellow. Uses compact
  Kailh mid-height switches to reproduce the real inter-button spacing.

License
: None specified — all rights reserved.

References
:   - [Project repository](https://github.com/3araht/bandominedoni)
    - [Build video](https://www.youtube.com/watch?v=WzOsrSpjDgU)
